## 第三题 提莫攻击——列表遍历与状态重置(20 分)




在<英雄联盟>的世界中,有一个叫 "提莫" 的英雄.他的攻击可以让敌方英雄艾希(编者注:寒冰射手)进入中毒状态.(游戏中中毒持续 4 秒,`本题为了泛化,持续时间由输入给出`):

- 提莫在时刻 `t` 对艾希发起攻击,敌方英雄在时间区间 `[t, t + duration - 1](含两端)`处于中毒状态;

- 如果在中毒结束前**再次攻击**,中毒计时器会**重置**,重新持续 `duration` 秒.

给定一个按**非递减**排列的攻击时刻列表和 `duration`,求敌方英雄处于中毒状态的**总秒数**.

**输入格式:**

第一行两个整数 `n` 和 `duration`(空格分隔);第二行 `n` 个整数,表示每次攻击的时刻(非递减).

**输入示例 1:**

```text
2 2   n相当于总的攻击次数,duration 相当于中毒持续时间
1 4   第一秒攻击和第四秒攻击
```

**输出示例 1:**

```text
4   第一秒攻击后持续两秒，第三秒结束，第四秒再次攻击持续两秒，总共中毒四秒
```

(第 1 次攻击覆盖第 1,2 秒,第 4 秒的攻击覆盖第 4,5 秒,共 4 秒)

**输入示例 2:**

```text
2 2
1 2
```

**输出示例 2:**

```text
3
```

(第 2 秒再次攻击时中毒还没结束,计时器重置,覆盖第 1,2,3 秒,共 3 秒)

**提示:** 可以逐个遍历攻击时刻,维护"当前中毒结束时间";新攻击若在中毒未结束前到来,只补充重叠部分并重置结束时间.注意最后一次攻击的贡献.

**评分标准:**

- 正确读入攻击时刻与 `duration`(5 分)
- 相邻攻击的重叠/重置处理正确(10 分)
- 最后一次攻击的持续时间计入总数(5 分)
